# OPD Sharing

A shared expense-reimbursement tool: upload a multi-page OPD (out-patient department) medical bill PDF, and the app splits it into individually claimable slips that a group of people can claim against, tracking who claimed what and how much of the group's shared reimbursement pool is left.

## Stack

- [Convex](https://convex.dev) — backend, database, file storage
- [Clerk](https://clerk.com) — authentication
- React + Vite + Tailwind
